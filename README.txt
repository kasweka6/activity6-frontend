RUN ON YOUR MACBOOK
1. Download and unzip activity6-frontend.zip.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select activity6-frontend.
4. Install the "Live Server" extension if it is not installed.
5. Right-click index.html and choose "Open with Live Server".
6. The website should open in your browser.

IMPORTANT
Do not open index.html by double-clicking it. Use Live Server because the JavaScript files use ES modules.

FEATURES INCLUDED
- Home, Manage Records and About navigation
- Responsive layout for phone and desktop screens
- Add, view, edit and delete maintenance requests
- Confirmation before deleting
- Search by title and filter by status
- Correct result count and summary cards
- Input validation and success/error messages
- Eight sample records
- localStorage browser demonstration data
- Automatically generated record IDs
- Separate HTML, CSS and JavaScript files

BEFORE SUBMISSION
1. Open index.html and check the site using Live Server.
2. In index.html, find the About section and replace:
   "Enter your name" with your correct name.
   "Enter your student number" with your correct student number.
3. Test adding a request, refreshing the page, viewing, editing and deleting.
4. Test the search and status filter.
5. Test the website on a narrow phone-sized screen and a desktop screen.
6. Deploy the activity6-frontend folder to Netlify using manual deployment.
7. Open the public Netlify URL and repeat the tests.
8. Submit the live Activity 6 frontend URL using the submission method given by your lecturer.

DATA NOTE
Records are stored in localStorage in the browser and website origin where they are created. They do not automatically appear on another device. Activity 7 and Activity 8 introduce the backend and connected system.

STUDENT DETAILS
The student name and number are left as placeholders. Fill them in before submitting.
